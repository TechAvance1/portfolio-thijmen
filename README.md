# Portfolio — Thijmen Alvarez

Een persoonlijke website voor de projectopdracht HTML & CSS. De website bevat twaalf losse HTML-pagina’s, één gedeeld CSS-bestand en lokale afbeeldingen. Er zijn geen frameworks, externe lettertypes of JavaScript nodig.

## Openen

1. Pak het ZIP-bestand helemaal uit.
2. Open de map `portfolio-thijmen`.
3. Dubbelklik op `index.html` om de website te bekijken.
4. Open de projectmap in Visual Studio Code om de code te bekijken en aan te passen.

## Inleveren via GitHub

De opdracht vraagt om een GitHub-link. Er is nog geen repository voor dit project aangemaakt.

1. Log in op je eigen GitHub-account en maak een nieuwe repository aan, bijvoorbeeld `portfolio-thijmen`.
2. Upload de **inhoud** van de uitgepakte projectmap, inclusief de submappen. Upload dus niet alleen het ZIP-bestand. `index.html` hoort direct in de hoofdmap van de repository.
3. Sla de bestanden op met een commit, bijvoorbeeld `Persoonlijk portfolio HTML en CSS`.
4. Open de repository en controleer of alle bestanden aanwezig zijn.
5. Lever de URL van de repository in bij de docent. Zorg dat de docent toegang heeft als je repository privé is.

GitHub Pages is optioneel; de broncode in de repository is al via een GitHub-link te delen. Het ZIP-bestand bevat de complete projectmap zoals de opdracht ook vraagt.

## Controleer je eigen inhoud

De teksten zijn gebaseerd op de informatie die je eerder hebt gedeeld. Controleer vooral de officiële naam van je mbo 2-diploma, je werkzaamheden en de huidige status van je projecten voordat je inlevert. Projectideeën zijn als concept of experiment omschreven en niet als bewezen afgeronde producten.

Er is gekozen voor een eenvoudige computerillustratie in plaats van een persoonlijke foto. Privécontactgegevens en gegevens van andere personen zijn niet opgenomen.

## Formulier

Het contactformulier is een HTML/CSS-oefening. Het verzendt en bewaart niets. De verzendknop is bewust uitgeschakeld; de resetknop werkt wel. Een echte verzending vraagt om een server of een externe formulierdienst en valt buiten deze statische opdracht.

## Hulp en eigen begrip

Deze uitwerking is met AI-hulp opgesteld. Lees de code en de uitleg, pas de teksten aan waar nodig en zorg dat je kunt uitleggen hoe de website werkt. Volg de afspraken van je docent over het vermelden van gebruikte hulpmiddelen.
